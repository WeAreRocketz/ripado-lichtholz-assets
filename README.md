# Lichtholz / Ripado — website image assets

Versioned images used by the Lichtholz product page recreated in Ghozt. Published independently of the Shopify file library so deleting an upstream Shopify file does not remove this copy.

These are the assets of a single website, not a general-purpose image hosting service. Media rights remain with their respective owners; publication here does not grant a new license to reuse the images.

`manifest.json` records original URL, semantic filename, byte size and SHA-256 for every image. The project owner keeps an additional local backup. Use commit-pinned CDN URLs for immutable versions.
